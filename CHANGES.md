# Visible-monitoring edition

The supplied attachment was a repeated, contradictory requirements document rather than Android source code. This repository is a new implementation of the normal, visible behaviour requested in the accompanying message.

- Standard camera, microphone and notification permission requests.
- Real Teacher status instead of an always-offline display.
- Foreground Monitoring active notification and local Stop controls.
- Android privacy switches/indicators left intact.
- No hidden launcher, silent permission grants, notification suppression or boot receiver.
- No remote restart following force-stop, reboot or service termination.
- Local activation and confirmation for resetting pairing.
- One paired administrator, H.264/AAC over authenticated WSS, role checks and bounded media queues.

See README.md for implemented functions and operating limits, and TESTING.md for verified results. No code from an older Online Teachers ZIP was used or modified in this delivery.
